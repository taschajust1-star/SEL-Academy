# SEL Academy — Manifestation Decision Copilot

This documentation package defines a legally aligned, human-in-the-loop decision support framework for manifestation determination, discipline decision support, and regulation-aware intervention planning.

## Included docs

- `LEGAL_GUARDRAILS.md` — legal scope, prohibited uses, required safeguards
- `OUTPUT_TEMPLATE.md` — legally safe output format
- `RULE_ENGINE.md` — rule-based decision engine with compliance-aware language
- `ETHICS_LAYER.md` — ethics and bias mitigation layer
- `COMPLIANCE_CHECKLIST.md` — deployment and operations checklist

## Positioning

This system is advisory only. It is designed to support team-based decisions under IDEA, Section 504, ADA, FERPA, and Minnesota law. It does not replace IEP or 504 team judgment.

## Core principle

The system is built to answer:

> What support is indicated?

not:

> What is wrong with this student?

## Notes

This documentation emphasizes:

- observable patterns over speculative labels
- contextual interpretation over rigid classification
- support-oriented outputs over punitive framing
- transparent logic over black-box automation
